# North Wharf Ferries baseline

Brownfield starting app. Created 6 October 2026 with `npx create-next-app@latest baseline --yes`.

Pinned by that install: Next.js 16.3.8, React 19.2.8.

`/` lists today's sailings. `/staff` can mark a sailing delayed. There are no holds and no database. Sailings live in `lib/sailings.ts`.

```bash
npm run dev
```
